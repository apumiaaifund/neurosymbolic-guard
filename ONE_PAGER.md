# APUMIA Guard — Нейросимволический и кинематический предохранитель для ИИ и робототехники

**Проблема:** Современные LLM-агенты и VLA-модели (Vision-Language-Action) вероятностны. В корпоративных системах одна галлюцинация или промпт-инъекция приводит к несанкционированным списаниям и утечкам данных, а в автономной робототехнике, складских AMR и БПЛА — к превышению тормозного пути, столкновениям с людьми и сбоям при потере сенсоров.

**Решение:** Двухуровневый детерминированный контур безопасности **APUMIA Guard**, который перехватывает команды нейросети до их исполнения и проверяет по строгим математическим и физическим инвариантам:

1. **Cloud / Enterprise Core (Python + SMT-солвер Z3, 1–3 мс):**
   - Компилирует декларативные YAML-политики безопасности в формальные логические уравнения без `eval` и риска RCE.
   - Блокирует превышение финансовых лимитов, нарушения ролевой модели и попытки обхода ограничений через промпт-инъекции.
   - Поддерживает цикл мгновенной самокоррекции ИИ-агента с объяснением причины отказа.

2. **Edge / Robotics Core (Zero-Panic Rust + PyO3 + ROS 2 / MAVLink, < 1 мкс):**
   - Работает на бортовых контроллерах (ARM64 / x86) без зависимости от облака и GPU.
   - Принудительно ограничивает скорость по физике тормозного пути (учёт коэффициента трения поверхности $\mu$), вводит защитную зону вокруг человека (`< 2.0 м` → лимит `0.4 м/с`) и переводит систему в `EmergencyStop` при аномалиях сенсоров (`NaN`/`Inf`).
   - Включает готовые адаптеры для **ROS 2 (`geometry_msgs/Twist`)** и **MAVLink**.

3. **Криптографический «чёрный ящик» (`FlightRecorder` + Live WebSocket):**
   - Каждое решение фиксируется в непрерывной хеш-цепочке (FNV-1a / HMAC-SHA256) с экспортом в JSON и реальтайм-мониторингом по WebSocket для службы безопасности и расследования инцидентов.
